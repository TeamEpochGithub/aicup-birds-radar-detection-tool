📖 User Manual & Tutorial

1. About This Tool

This is an interactive visualization and Feature Engineering tool for the AI Cup 2026: Bird Track Radar Challenge. It allows you to explore bird flight paths and debug AI models directly in your browser. Github Repository

2. Interface & Navigation

  • 3D Map: Displays flight paths over Eemshaven. Left-click & drag to pan. Right-click & drag to tilt and rotate the 3D camera.
  • Track Details: Click any colored track on the map to open the Analysis Panel. This shows the specific 3D altitude profile and Radar Cross Section (RCS) of that bird.
  • Grid View: Toggle between "Map" and "Grid" in the top right to view tracks as a sortable table.
  • Filtering: Use the left sidebar to search for specific Track IDs, filter by Bird Species, or isolate specific days.
  • The Data: Each radar "track" is a series of measurements containing 4 elements: Longitude, Latitude, Altitude (m), and Radar Cross Section (dB).

3. Feature Calculator & Filters (Python)

You can write Python code in the left sidebar to extract features or filter the dataset in real-time.

Available Variables
  • coords (N, 4)
    [Longitude, Latitude, Altitude (m), RCS (dB)]
  • times (N,)
    Relative timestamps in seconds (float).
  • meta (dict)
    Contains CSV columns: airspeed, radar_bird_size, plus injected debug columns. meta['is_test'] is True for test set tracks.
Return Value for features

Your function must be named calculate and return a flat Dictionary of numbers. These become Green Columns in the Grid.

def calculate(coords, times, meta):
    import numpy as np
    z = coords[:, 2]
    return {
        "max_height": float(np.max(z)),
        "duration": float(times[-1] - times[0]),
        "metric": meta['airspeed'] * 2
    }

Return Value for filter

Your function must be named filter and return True to keep the track and False to hide the track

4. Submissions & Debugging

Upload your local submission.csv (via the 📤 Submission button) to overlay your AI predictions on the map and calculate your local mAP score.

Standard Kaggle Format
track_id, Clutter, Ducks, Geese, ... (probabilities)
Debug / Enhanced Format (For this tool)
track_id, Clutter, ..., cv_fold, embedding_x
  • Superset Submissions: Your uploaded CSV can contain tracks from train.csv (for local hold-out validation) alongside test tracks.
  • Debug Columns: Any extra columns in your submission file are automatically rendered as Pink Columns in the Grid View. These values are injected into the Python meta dictionary so you can filter by them (e.g., meta['cv_fold'] == 1).
  • Note: If you want to use your local Python environment instead of your browser's CPU, install the local server version from Github.
  • mAP score: The average precision score is only calculated over the train tracks if provided. To calculate the test track, for the public leaderboard, you must submit it on Kaggle

5. Statistics Lab (📊)

Class Boxplots Runs your Python feature calculator against the dataset and plots distribution boxplots grouped by Bird Species. Useful for finding features that separate classes well.
Train/Test Overlap Plots histograms comparing the distribution of your features in Train vs. Test sets. Crucial for detecting Covariate Shift.
