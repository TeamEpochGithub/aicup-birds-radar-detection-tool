📖 User Manual & Tutorial

1. About This Tool

This is an interactive Feature Engineering & Error Analysis tool for the AI Cup 2026: Bird Track Radar Challenge.

The goal is to classify radar tracks into bird species. Github https://github.com/TeamEpochGithub/aicup-birds-radar-detection-tool, licensed under MIT

2. Data & Loading

  • Auto-Load: The app tries to fetch train.csv and test.csv automatically (cached in your browser for instant reloads).
  • Manual Load: Drag-and-drop your own files via the 📂 CSV button.
  • The Data: Each "track" is a sequence of 3D points [Longitude, Latitude, Altitude] plus RCS (Radar Cross Section) recorded over time.

3. Feature Calculator (Python)

Write Python code in the left sidebar to extract features or filter data.

Available Variables
  • coords (N, 4)
    [Longitude, Latitude, Altitude (m), RCS (dB)]
  • times (N,)
    Relative timestamps in seconds (float).
  • meta (dict)
    Contains CSV columns: airspeed, radar_bird_size, plus any injected debug columns.
    meta['is_test'] is True for test set tracks.
Return Value

Your function must return a flat Dictionary of numbers. These become Green Columns in the Grid.

def calculate(coords, times, meta):
    import numpy as np
    z = coords[:, 2]
    return {
        "max_height": float(np.max(z)),
        "duration": float(times[-1] - times[0]),
        "my_custom_metric": meta['airspeed'] * 2
    }

4. Submissions & Debugging

Upload your local submission.csv to overlay predictions on the map and calculate mAP (Mean Average Precision).

Standard Format
track_id, Clutter, Ducks, Geese, ... (probabilities)
Debug / Enhanced Format
track_id, Clutter, ..., cluster_id, embedding_x, local_outlier_factor
  • Important: The submission.csv you upload here can be a Superset of the Kaggle submission. It can contain tracks from train.csv (for local hold-out validation) and does not need to be limited to just the test set.
  • Debug Columns: Any extra columns in your submission file are automatically detected as Pink Columns in the Grid View. Debug columns are invalid for kaggle submissions.
  • These values are injected into the meta dictionary (e.g., meta['cluster_id']), allowing you to visualize your local training pipeline's internal state.
  • Test Set: Since ground truth is unknown for the test set, uploading a submission allows the tool to use your Predicted Class as the label for visualization and filtering.
  • TIP: generate two submission files from your pipeline: 1. for kaggle and 2 that contains train and debug info for the bird radar site.
  • The Epoch website executes the python in your browser. If you want to use your local python environment, please install the tool from Github

5. Statistics Lab (📊)

Class Boxplots Runs your Python feature calculator against the entire dataset and plots distribution boxplots for every returned feature, grouped by Bird Species. Useful for finding features that separate classes well.
Train/Test Overlap Plots histograms comparing the distribution of your features in Train vs. Test sets. Crucial for detecting Covariate Shift (e.g., finding if test birds fly higher/slower than training birds).
